Post-mortem: binding constraint was thin scaling margin combined with bad luck. By the ante-1 boss we had
only ONE joker (Crafty Joker) and it was tied to Flush, a hand type we rarely completed and that was NOT
our actual main hand (Two Pair, which we had just leveled via Uranus). So the Two Pair engine that carried
the whole run had zero dedicated flat-mult/chips joker (no Mad Joker/Clever Joker equivalent appeared in
the ante-1 shops) — only the L2 hand level. That was enough to get to 538/600 with 3 hands + discards, but
the final hand, forced with 0 discards remaining, drew an unpaired 7-card hand (A-K-Q-J clubs, 6-4-2 off)
with no possible pair/straight/flush, capping the last hand at High Card (~16) instead of the ~62+ needed.
This is largely draw variance on the last hand, but the underlying risk (single mismatched joker, no
backup scaling) made the margin razor-thin at 600 needed in ante 1.

Decision I would change: at the ante-1 Buffoon Pack, Crafty Joker (Flush) vs Campfire were the only two
options and neither matched a Two Pair engine — this was a bad pack draw, not obviously a misplay given the
information at the time (we had just won the Small Blind with a flush). In hindsight, given Two Pair was
clearly the emerging engine (a made pair showed up in nearly every hand this run), it would have been worth
rerolling the shop once (if affordable) or accepting Campfire instead, planning to sell early jokers into it
once it's fed by any consumable/joker sale, rather than banking on a Flush joker for a Two-Pair-driven run.
Neither is a slam dunk fix, but the mismatch meant our only joker contributed 0 to the losing hand and near-0
across the whole run.

Bridge issues: none. Every `disc`, `play`, `pick`, `buy`, `use`, `cash`, `blind`, `advise`, `shopadvise` call
succeeded on the first try; no `ACTION FAILED` retries were needed, no transient Python errors.

Est vs actual: est matched actual scored in every single hand this run (Two Pair 116->112 note: est was

Playbook suggestions:
1. When a Buffoon Pack's only options are jokers mismatched to the hand already in progress (e.g. a
   Flush-tied joker when Two Pair is the emerging main hand), consider noting in the log to prioritize a
   MATCHING flat joker in the very next shop over any further hand-level purchases, since a hand level alone
   (L2 Two Pair, no dedicated joker) was insufficient margin to clear the ante-1 600 boss on a bad last draw.
2. Add explicit guidance for The Tower tarot (converts a random card to a Stone Card, no rank/suit): flag it
   as a risk for pair/trips-based engines specifically (mirrors the existing note about not building around
   xMult scarcity) so shopadvise's generic ADVICE line doesn't default to buying it against a pair engine
   without a caveat.
3. Consider having `advise`/`hands` warn when a round is down to its FINAL hand with 0 discards and the
   estimated best is far below need (e.g. "final hand, no discards, est X << need Y: this blind is likely
   lost") so the agent can flag the outcome clearly rather than only discovering it via GAME_OVER.
