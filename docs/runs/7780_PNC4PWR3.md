## Post-mortem

Binding constraint: scaling/timing — went into the Big Blind with zero scoring jokers (only Astronomer, a
pure utility/economy joker with no chip/mult effect), so three hands of two-pair/flush at L1 with no joker
mult topped out at 116+252+72=440, ten points under 450. Not a misplay in any single hand (every `est`
matched the actual score exactly, so the CLI/advise math was reliable) — the loss was baked in once the
only available joker in the ante-1 Buffoon Pack pick was Astronomer/Popcorn, neither of which adds chips
or mult.

Decision I would change: at the ante-1 shop, `shopadvise` correctly flagged Popcorn as AVOID (self-destruct
risk) and Astronomer was the only other pack option, so within that pack there was no better pick. The real
lever was upstream: with $9 in the shop, buying the Buffoon Pack was the only advised action, but the pack's
2-card pool (Astronomer/Popcorn) had no scoring joker at all this run — pure bad luck on pack contents, not
a process error. If I could replay it, I'd still take Astronomer over Popcorn, but this run was likely lost
the moment the pack rolled no scoring joker for ante 1, per playbook 7 ("Batch 1 ... all lost in ante 1-2":
no first joker). Playbook already tells us to prioritize a scoring joker; there was simply none on offer
this run.

Bridge issues: none. Every `advise`/`shopadvise` recommendation was followed and every `est` matched the
actual scored delta exactly (316/316, 116/116, 252/252, 72/72) — no CLI or estimation discrepancies >20%
(all were 0% off).

Playbook suggestions:
1. When the ante-1 Buffoon Pack yields no scoring joker (both options are utility/decaying, e.g.
   Astronomer/Popcorn), consider explicitly noting this is a high-risk state for the Big Blind and, if
   affordable, rerolling the shop once before opening the pack (or immediately after) to look for a shop
   joker slot with a scoring option, even under the ">= $10" reroll-money guideline — currently the
   guideline blocks any reroll below $10 in ante 1-2 even when the alternative is a near-certain loss.
2. `shopadvise`/`advise` are highly accurate (0% deviation this run) — no changes needed there.
3. Consider having `advise` warn explicitly when a required final-hand play's `est` is below `need` and no
   jokers are held yet (e.g. "WARNING: this ante may be unwinnable with 0 scoring jokers") so the agent can
   flag the run as high-risk before committing hands, rather than only discovering it at GAME_OVER.
