Post-mortem: binding constraint was scaling pace, not money or a single misplay. By ante 3 Big Blind we had 0 xMult
jokers and two L2 hand levels (Straight, Two Pair) split across hands instead of consolidated into one, plus Full House
(our best-scoring hand type, 3 plays in the ante-2 boss) never got leveled at all because Earth was never offered in
either Celestial pack. Droll Joker (+10 mult if Flush) also went completely unused after ante 2 since we never drew
another flush -- a $4 joker that stopped contributing. The one decision I would change: in the ante-2 shop I should have
skipped the Jumbo Celestial Pack gamble (no Jupiter/Earth appeared either time) and instead saved toward directly buying
whichever planet showed up for our actual highest-scoring hand (Full House), rather than accepting Saturn/Uranus as
consolation levels that diluted focus across three different hand types (Straight, Two Pair, Full House at L1) instead
of stacking levels into one.

Bridge issues: none. Every `play`/`disc`/`pack`/`use` command behaved as documented; `est` matched actual score in
every hand this run (no bridge estimate was off by >20%).

Playbook suggestions:
1. When a Celestial pack whiffs on the main hand's planet twice in the same run, the playbook should say "buy nothing
   from it, or pick the planet for the hand you have scored HIGHEST with this run" rather than "consolation planet" --
   we ended up with 3 different hands at L1-L2 instead of 1 hand at L4+, which is exactly the diluted-levels trap the
   playbook otherwise warns against.
2. Consider flagging jokers like Droll Joker (+mult if Flush) as risky picks in ante 2 when the player's actual played
   hands that ante were a mix of types (not committed to Flush) -- it can become a dead slot the moment the flush luck
   dries up, same caution the playbook already gives Gluttonous/suit jokers should extend to single-hand-type flat mult
   jokers when the main hand is not yet locked in.
3. The Magician tarot's Lucky-Card enhancement is a low-probability rescue (each card only 1/5 to add +20 mult) --
   worth using per the "never concede" rule, but the playbook's 4.8 section should note this specific tarot has a real
   chance of doing nothing (as happened here) so agents don't read "use it" as "this saves the hand."
