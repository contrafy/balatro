# Run XR4UMJBN (port 7780) - LOSS at ante 2 Big Blind

Stake 1 (White). Black Deck.

Ante 1 boss: The Pillar (600) - cards played earlier this ante are debuffed at boss. Plan: play Small/Big with as few cards as possible, avoid committing engine cards.

Ante 1: bought Supernova ($5, +mult per repeat play) and Blackboard ($6, x3 if all held cards Spades/Clubs, xMult). Small Blind: Two Pair(120)+Flush(280)=400/300, won. Big Blind: Full House(365)+Pair(90 fillers)=455/450, won. Boss The Pillar 600: spades from earlier plays came back debuffed; kept drawing fresh flush/full-house material from unplayed suits, final line Flush(306, 2 debuffed cards scored 0)+HighCard filler(30)+Full House(456, 1 debuffed 8H scored 0)=792/600, won. Money end of ante: $2.

Ante 2 (boss The Wall, x2 chips, shown as 3200 target for boss - not reached): shop bought Hiker (picked from Buffoon Pack over Ice Cream, which the playbook AVOID list flags as self-destructive) and Gift Card (economy, +$1 joker sell/round; last $ available, no scoring jokers left in shop). Ordered jokers xMult (Blackboard) rightmost each time. Small Blind (800): Full House KKK66 (est 574, kept both discards to build it) + Pair 7 with fillers (`advise` estimated only 96 but actual scored 288 - see discrepancy note below) = 862/800, won. Big Blind (1200): Two Pair A6 (est 216) + High Card filler (est 48, actual 144) + Pair 9 (est 140, actual only brought total to 500) = 500/1200, LOST. Final hand had no pair/flush material left - deck ran cold after 3 discards spent early keeping a Two Pair that never repeated (Supernova synergy wasted since we changed hand type each time) and Blackboard (x3 all Spades/Clubs) never fired all run because held cards were always suit-mixed.

Post-mortem: binding constraint was SCALING - the joker package (Supernova, Hiker, Gift Card, Blackboard) had no reliable xMult trigger. Blackboard's "all held cards Spades/Clubs" condition is nearly impossible to satisfy with an 8-card hand drawn from a 52-card deck without dedicating discards purely to suit-filtering, so it never multiplied anything in this run. Supernova only pays off when the SAME hand type is replayed repeatedly; we played Full House/Two Pair/Pair/High Card in a scattershot way instead of committing to one repeatable type, so its scaling never compounded. Money was also thin ($1-3 most of ante 1-2), leaving no buffer to reroll for a better xMult joker or to buy planets to level a main hand.
The one decision I would change: at the ante-2 shop, instead of buying Gift Card (pure economy, no board impact) I would have kept the $6 (or rerolled once) hoping for a real +mult/xMult joker, since Blackboard was already a dead pick and the shop had nothing else scoring. Also, committing to ONE hand type (Full House, which we could reliably make) every single hand to actually trigger Supernova's growth would have been better than switching hand types (Two Pair -> High Card -> Pair) each time.
Case where `est` differed from actual score by >20%: Ante 2 Small Blind, "PAIR 4 5 7 2" was estimated at 96 but scored 288 (3x, +200%) - likely because `advise`'s est did not fully account for Supernova's mult scaling with prior plays of the same type at that point in the round. Also "HIGH 1 8 7 6 5" (ante 2 Big Blind) estimated 48, actual 144 (3x, +200%), and "TWOPAIR 1 2 5 6 8" est 216 vs later total delta implying similar underestimate. This is the second run in a row (see prior runs if any) where Supernova-style "scales with plays" jokers were underestimated by `advise`.
Bridge issues: none - no ACTION FAILED, no Connection refused, no misreads. All `play TYPE` commands succeeded on first try.
Playbook suggestions:
1. Add Blackboard (and any "all held cards must be suit X/Y" joker) to a caution list: note that it is very hard to trigger reliably without dedicating several discards purely to suit-filtering every single hand, and playbook should recommend NOT prioritizing it over a flat +mult/reliable xMult joker unless the player is already deep into a mono-suit strategy.
2. `advise`/`hands` est appears to systematically underestimate jokers that scale with "times this hand type has been played" (e.g. Supernova) - actual scores came in 2-3x the estimate twice in one run. Worth flagging in section 3 that these jokers' `est` should be treated as a floor, not a ceiling, and that this makes case for committing to ONE repeatable hand type more attractive than `advise`'s printed numbers alone suggest.
3. Consider adding explicit guidance for boss "chip multiplier" bosses (The Wall, Violet Vessel) that the DISPLAYED target already includes the multiplier (confirmed here: ante 2 boss shown at 3200 = 1600 base x2), so no separate mental doubling is needed when reading targets.
