## Post-mortem

Binding constraint: scaling. The only multiplier all run was polychrome Baron (x1.5 flat, x1.5 more per King held,
which is card-phase and only multiplies the base mult). Everything else was flat: Swashbuckler (+38 via Egg), Abstract
(+24), Smiley, Odd Todd, Ice Cream, Zany. Zero r/g xMult was offered in 11 shop views (one reroll). Ests were exact
all run (8742/8742, 25096/25096, 15621/15621), so the 541 deficit was certain before the last hand.

Decisions I would change:
1. Ante 3 Small shop: I bought Jolly{PERISH} $3 over the advisor's Mercury $3. Jolly perished before ante 5; Pair L3
   would have added +15 chips +1 mult to the final Pair AA (164 -> 179 chips, mult 95 -> 97.5 = ~17450 > 16162):
   the run would have survived. The ante-2 shop also offered Mercury $3 that I passed.
2. Ante 5 Big shop: left with $12 and lost by 541. Idle money at ante 5 with no xMult is the playbook's "lost run";
   a second reroll ($5) was the only remaining shot at a multiplier or a Mercury, and interest never got spent.
3. Ante 5: sold Splash for Abstract. Correct for typical hands (+24 mult), but note a Water/no-discard final hand is
   usually a lone pair, where Splash fillers (TC 8D 5H + Todd) would have added ~+54 chips.

Reusable rules (if-then):
- IF you own Swashbuckler, THEN Egg (Eternal or not) is a growth +mult joker: +3 mult every round end, permanently
  (it went +2 -> +20 here). Also, every round you skip is -3 mult on it.
- IF The Mark leaves 5 face-down cards in hand, THEN play all 5: J/Q/K only, so 5 of them are always Two Pair, Trips,
  Full House or Quads (advisor suggested 4, which only guarantees a Pair).
- IF The Water (or The Needle) is the ante's boss and you hold no xMult, THEN buy the $3 Mercury when offered: no-discard
  rounds end on a forced lone Pair far more often than on your main hand; one Pair level is worth ~4% there.
- IF a Celestial pack shows Black Hole, THEN take it over the main-hand planet (it levels the main hand too).
- IF a negative joker is Eternal, THEN its Eternal sticker costs no slot: free negative Zany = +12 on trips and +7
  mult via Swashbuckler (sell $4) + Abstract (+3).
- IF your best final hand est (exact all run) is a few % short and you have no consumable, THEN the loss was decided in
  the previous shop: from ante 5 spend down to the floor on any +chips/+mult/level that fires on Pair before leaving.
