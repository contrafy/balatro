Post-mortem:
- Binding constraint: SCALING. The main hand (Two Pair/Full House family) never left Level 1 the entire run - no Uranus,
  Earth, or any fitting planet was ever bought or offered at an affordable price alongside a joker buy. All scoring came
  from flat jokers (Smiley/Scary/Half/Card Sharp) plus lucky face-heavy and straight draws; there was zero xMult beyond
  Card Sharp's conditional x3, and zero permanent card enhancement other than one Glass King and one Steel Queen (both
  used/played before The Tooth, so neither was still held to help there). Against The Tooth's steep per-card cash penalty,
  we needed a hand that scores enough for the ante with fewer, cheaper cards - only possible with a truly leveled main hand
  or a joker that fires on <=3 cards consistently (Half Joker did fire, but was not enough alone at ante 4's 16000 total).
- Decision I would change: at the ante-2 shop (docs above, $5 -> buy Scary Face $4 -> $1), I left only $1, missing the
  directly-offered Uranus $3 (Two Pair's own planet) in the very next shop. Keeping $4 that one time (per the "$4 after any
  pack/planet/voucher" rule, which applies to jokers too when a same-shop planet is visible) would likely have let the main
  hand reach L2-L3 by ante 3, which compounds into every later hand including the fatal Tooth straight.
- Bridge/CLI: no problems. Every `est` matched the actual score to the chip exactly across ~15 hands this run (0% deviation,
  including the final losing hand) - the estimator is trustworthy for go/no-go decisions here. No ACTION FAILED, no retries,
  no connection issues.
- Playbook suggestions:
  1. Add an explicit rule: "if a same-shop planet for your main hand is visible and affordable, buying it takes priority
     over a second flat joker once you already own one scoring joker" - this run bought 3 flat face jokers before ever
     landing a single hand-level, and paid for it against a per-card-cost boss.
  2. Add to section 4.8 (last-hand consumable check): explicitly note that Strength/Death are worthless on a hand that is
     ALREADY the maximum-value made hand available (e.g., an Ace-high straight) - rank-up or copy can only downgrade such
     a hand, so don't spend time trying to force them in that case; the check is only useful when the best made hand is
     NOT already using its own best cards.
  3. Card Sharp's "register cheap, then x3" pattern (section 7a) worked exactly as documented three separate times this run
     (all three `est` predictions were exact) - worth calling out in the playbook as validated/reliable, not just theoretical.
