Post-mortem: binding constraint = SCALING. This run never acquired a second joker, let alone a Pair-floor
scorer (Scary Face only fires on face cards, so a Two Pair of low pairs scores it nothing). Ante 2's Small
Blind is already 900 at Green Stake, and a flush chase with 0 jokers is a coin flip that this run lost. The
one decision I would change: at the ante-1 post-boss shop ($7, Riff-raff $6 + voucher only), buying
Riff-raff would have been worth reconsidering despite shopadvise's LEAVE - it generates jokers, and any
additional joker (even a weak one) beats entering ante 2's 900-chip Small Blind with a single face-gated
joker and no Pair scorer. More fundamentally, this confirms the existing playbook note (7.a "STAKE 3 ANTE
1-2"): a jokerless-for-Pairs deck cannot reliably clear the ante-2 900 Small Blind at Green Stake even with
a flush chase, because the chase itself is a coinflip with no fallback once discards run out.

Bridge issues: none. Every command returned the expected state; no `ACTION FAILED` or retry was needed
this run.
