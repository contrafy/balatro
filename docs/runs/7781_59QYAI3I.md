Money curve: ante1 $4->$9->$5(post-buy)->$6; ante2 $6->$4(post-Wee Joker)->$1(post-Misprint)->$9->$3->$5; ante3 $5->$11->$5(post-Duo)->$1(post-Celestial)->$8; ante4 $8->$10(post-CardSharp)->$0(post-Arcana+planets)->$4->$1(post-Uranus)->$6->$6(shop skip)->$6(death, no cashout).
Binding constraint: boss mechanic (The Goad debuffing Spades) combined with a run whose only leveled pair-family hand was Pair L2 and whose main scaling joker (Card Sharp) needs the SAME type repeated, but our hand kept drawing spade-heavy cards that were debuffed and contributed nothing, forcing weak Pair plays into a 10000 target that our jokers/levels could not reach in time. Secondary factor: no card-targeting tarot (Death/Justice/Strength) was held in reserve for this boss - both Arcana/Celestial pulls that shop were spent on planets (Earth, Saturn, Uranus) rather than banking a rescue tarot, so the last-hand check (playbook 4.8) had nothing to use.
Decision I would change: at the ante-4 shop (before The Goad), given "Upcoming boss: The Goad" was visible and our only strong xMult+level combo (Pair L2 + Card Sharp + Duo) is spade-vulnerable in a Spade-heavy deck moment, I would have kept a held tarot (Strength/Justice) in reserve instead of spending both High Priestess planets (Earth, Saturn) plus Uranus immediately - a rescue tarot on the final Pair 7 hand (turning the debuffed 7S into a scoring card, or ranking up a dead card into the pair) likely closes the ~2120 gap.
Bridge/CLI issues: none - no ACTION FAILED, no connection issues, no misreads. advise/hands/shopadvise commands all functioned as documented throughout.
Est vs actual calibration: est consistently UNDER actual by 30-80% throughout the run whenever Misprint's random mult (0-23, conservative-6 estimate) or multiple flat-mult jokers stacked (e.g. Big Blind ante2: est 1984 vs actual 3614, +82%; Small Blind ante3: est 2496 vs actual 4524, +81%; Big Blind ante3 second hand: est 2816 vs actual 4608, +64%; Boss ante3: est 4784 vs actual 8400, +76%). Playbook suggestions:
1. When a boss's suit-debuff (Goad/Club/Window/Head) is upcoming, the shop procedure should explicitly recommend holding back at least one consumable slot for a card-targeting rescue tarot (Death/Justice/Strength) rather than spending all pack pulls on planets, especially when the run has no reroll cushion.
2. `advise`'s last-hand warning (before a forced final hand under need) should proactively remind the agent to check held consumables even when none are currently held, so the absence is a deliberate/logged decision rather than a default.
3. Misprint's random mult swings the actual score 30-80% above the conservative estimate consistently; worth flagging in the playbook's "Do-not list" that Misprint should not be relied on as a floor-est joker for planning discards near the need threshold - it will usually beat estimate but should not be counted on to close a large gap precisely.
