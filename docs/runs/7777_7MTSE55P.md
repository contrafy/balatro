# Run 7MTSE55P (port 7777) - LOSS at ante 1 Big Blind

Stake 1 (White Stake), Black Deck.

Ante 1: Small Blind tag=Economy, Big tag=Double, Boss=The Club (suit debuff, never reached).
- Small Blind (need 300): discarded 3x chasing Hearts flush (est climbed 268->296), played Flush est 296 (actual
  296), then Pair-of-Kings est 60 (actual 60) to finish 356/300. Cleared.
- Shop 1 ($8, 0 jokers): shopadvise ADVICE was `buy 2` (Satellite $6, ECON: +$1/unique planet). Overrode per
  playbook 5 (ante 1-2: buy first scoring +mult/+chips joker; Satellite/Mime are non-scoring) and opened
  Buffoon Pack ($4) instead. Choice was Spare Trousers (+2 mult per Two Pair played) vs Scholar (Ace bonus).
  Picked Spare Trousers. Left with $4, shopadvise then said LEAVE (nothing affordable) - endshop.
- Big Blind (need 450): discarded 3x chasing Hearts flush again (est 320, could not improve further with
  remaining discards). Played Flush est 320 (actual 320, running total 320), Pair-of-3s est 32 (actual 32,
  total 352), Pair-of-Kings est 60 (actual 60, final total 412). 412 < 450 -> LOST. GAME_OVER.

Post-mortem: binding constraint = misplay/build mismatch, not money or scaling. I never played a single Two
Pair hand all run, so Spare Trousers (+2 mult per Two Pair played) contributed 0 - a wasted joker pick chasing
a hand type (Two Pair) that didn't match what I was actually drawing/playing (Flush, then Pair). The real
problem: my hand kept resolving to Flush or Pair, never Two Pair, so the only joker I owned never fired, and
I had no +mult/+chips joker that helps ANY hand shape (e.g. plain Joker/Jolly/Zany would have added flat value
regardless of hand type). By the last hand of the Big Blind, need (98, then still short after best available
Pair-K est 60) exceeded what a jokerless-in-practice hand could produce, and I had no discards or hands left
to recover.

Decision I would change: in the ante-1 shop, when Buffoon Pack offers only conditional/hand-type-specific
jokers (Spare Trousers = Two Pair only, Scholar = Ace only) and neither guarantees firing given my actual
draws, prefer a joker that scores unconditionally (flat +mult/+chips regardless of hand type) if the pack
had one, or, lacking that, favor the joker whose trigger condition is closest to the hand type I am actually
building toward (I was flushing, so neither option was ideal - should have valued "how often will this
condition actually be true THIS run" over long-term scaling potential at ante 1, where there's no time to
pivot).

`est` vs actual: no deviations more than 20% - every played hand's `est` matched the actual scored value
exactly (Flush 296->296, Pair 60->60, Flush 320->320, Pair 32->32, Pair 60->60). CLI/bridge estimation was
accurate throughout.

Bridge issues: none. Every command (`s`, `advise`, `hands`, `disc`, `play`, `cash`, `shopadvise`, `pack`,
`pick`, `endshop`, `blind`) returned cleanly on the first try; no `ACTION FAILED` or retry needed this run.

Playbook suggestions:
1. Section 5 ante 1-2 rule "buy the FIRST affordable joker that adds mult or chips" should explicitly warn
   that a conditional joker (Two Pair only, Pair only, Ace only, etc.) picked from a Buffoon Pack is a gamble
   if the player's actual hand composition that ante doesn't match the condition - prefer an unconditional
   flat +mult/+chips joker (Joker, Zany Joker) over a hand-type-specific one at ante 1 when both are choices
   in the same pack, since there's no time yet to know which hand type the deal will support.
2. Consider adding a rule of thumb: if the best made hand's `est` falls short of `need` by more than ~30%
   even after using all discards, and no filler cards can plausibly close that gap (no suit/rank imminent),
   flag this explicitly as "this blind is likely lost" so the agent stops burning discards on marginal
   improvements (268->296->320, three discards for +52 est) and instead preserves a discard as an emergency
   card-targeting-tarot / different-hand pivot option, if one is available.
3. `shopadvise`'s ECON/UTIL recommendation at 0-1 jokers should be weighed against playbook 5's explicit
   ante 1-2 rule (buy a scoring joker first); in this run shopadvise suggested Satellite (economy) with 0
   scoring jokers owned, which the playbook itself says to avoid until 2 scoring jokers are secured.
