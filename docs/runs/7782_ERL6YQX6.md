## Post-mortem

Best result this run: stake 1 (White), ante 4, lost to the boss blind The Arm at 8199/10000 (82%).
Final jokers (6/6): Devious Joker (+100 chips if Straight), Misprint (+0..23 random mult), Walkie Talkie (+10
  chips/+4 mult per 10 or 4 card), Golden Joker (+$4/round), Blue Joker (+2 chips per card in deck), Blackboard
  (x3 if all held cards Spades/Clubs - never actually triggered all run).
Final levels: Flush L3, Straight L4, Full House L2 (down from L3), Two Pair L1 (down from L2, both via The Arm),
  everything else at the Black Hole-boosted L2 baseline.
Money curve: $4 (ante1 start) -> $10 -> $17 -> $24 -> $28 -> $14 (spent down for Blackboard/rerolls) at loss.
  Never reached the playbook's "$25 by ante 4" target with room to spare; two failed ante-4 rerolls ($11 total)
  hunting for xMult cost real money without result.

Binding constraint: scaling. This run never assembled real xMult - Blackboard (bought ante 4, our only xMult
  source) needed a condition (all 8 held cards Spades/Clubs) that no dealt hand actually satisfied, so effectively
  the whole run was carried by flat chips/mult jokers (Devious, Walkie Talkie, Blue Joker) plus hand levels. That
  is exactly the failure mode the playbook warns about ("Money sitting idle... with no xMult is a lost run") -
  except here it wasn't idle money, it was money spent on a joker that never worked as intended.

One decision I would change: when Blackboard appeared as the only xMult option in the ante-4 shop, I should have
  recognized its condition (ALL 8 held cards same 2 suits) is very hard to satisfy reliably with random draws and
  no repeatable suit-fixing tool in hand (The World only converts the hand at cast-time, not future draws), and
  either skipped it for a flat +mult/chips joker plus kept rerolling for a more generically-triggered xMult (Hologram,
  Photograph, Card Sharp, Constellation - anything that doesn't require a whole-hand suit constraint), or bought it
  AND immediately built a plan to re-cast The World every shop to maintain the suit condition (we had 0 copies left
  by the final ante). Buying a hard-to-trigger xMult and never revisiting how to actually trigger it was the single
  biggest wasted spend of the run ($6 + 2 Arcana packs' worth of tarot picks).

Bridge issues (exact text): `cash` returned "ACTION FAILED: Round eval blocking events still pending, retry shortly
  None" three times total this run (after the ante2 boss, ante3 boss, and ante4 Big Blind); every time, sleep 2 then
  retrying the same `cash` command succeeded with no data loss. One `buy` attempt failed with "ACTION FAILED:
  buy_from_shop returned false: no space or card not purchasable None" when trying to buy a Planet card while both
  consumable slots were occupied by unused tarots - resolved by `sellc` on one tarot first, then the buy succeeded.

Playbook suggestions:
1. Add an explicit note that buying an xMult joker with a hand-composition condition (Blackboard, Ancient Joker's
   rotating suit, etc.) is only worth it if the deck/tarots can reliably maintain that condition every hand - a
   one-time The World/Star/Sun/Moon cast only fixes the CURRENT hand, not future draws, so these suit-locked xMult
   jokers need either a very suit-heavy remaining deck or a repeatable re-suiting method, otherwise treat them as a
   flat-mult joker's sell value, not a real xMult source.
2. The `est` vs `actual` miscalibration (>20% off, both directions) was extremely frequent this run - roughly 8 of
   12 boss/blind-clearing hands - and in every case the joker set included Misprint (random 0-23 mult, `notes` field
   assumes a flat 11 as the expected value). Suggest `advise`/`hands` either widen the estimate into a range (e.g.
   "est 1500-3800, using 11") or explicitly flag "high variance: do not treat est as a safe margin" when Misprint
   or similar random-effect jokers are present, so an agent knows to keep a bigger safety buffer or an extra discard
   in reserve rather than treating a single `est` number as reliable.
3. For The Arm boss, the playbook currently says "play only unleveled hand types" - but after a Black Hole spectral
   card, EVERY hand type is at least L2, so there is no truly "unleveled" type to fall back on. Suggest updating the
   guidance to "play your least-scaled-so-far hand type" instead of "unleveled", since Black Hole (or any all-hands
   level-up) makes the literal L1 condition unreachable for the rest of the run.
