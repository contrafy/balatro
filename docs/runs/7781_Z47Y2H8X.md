# Run Z47Y2H8X (port 7781) - LOSS at ante 1 Big Blind

Ante 1: start, $4, no jokers. Blind tags: Small=Juggle, Big=Coupon, Boss=The Psychic (600, need 5 cards exactly).
- Small Blind (need 300): dealt QQQ + fillers, discarded down twice to draw JJ, played FULL HOUSE QQQJJ

- Shop ($9): shopadvise -> bought Photograph $5 (x2 mult on first scoring face card). Then shopadvise ->

  Final hand (0 discards left): A,K,Q,J,9,5,5,3 - no straight (missing 10), no flush (max 3 of a suit),
  only PAIR 5 available, est 40. Played it (forced, only legal action): final score 400, need 450.
  LOST Big Blind ante 1. GAME_OVER.

Post-mortem: binding constraint = bad luck (card draws never produced a hand above weak pairs/trips on
the last two plays) COMPOUNDED by a joker choice that never scored: Photograph (x2 on first scoring FACE
card) never fired because no play all round included a face card in the scoring group (full house was
88833, two pair was 6644, final hand was pair of 5s); Reserved Parking is pure economy and never adds to
score either. Effectively this run entered the Big Blind with 0 jokers that reliably add chips/mult
regardless of draw, violating playbook 5's "buy the first affordable joker that adds mult or chips to
hands you can make" -- neither shop offering (Photograph, then Buffoon Pack's Reserved
Parking/Smeared Joker) was a flat +mult/+chips joker, and none was on offer to pick instead.
One decision I would change: with the Buffoon Pack offering only Reserved Parking vs Smeared Joker
(neither scores), I'd flag that the shop had NO scoring joker available all ante-1 visit and consider
rerolling before endshop if money allowed (it did not: $0 after both buys) -- or spend more conservatively
on the first buy to keep $ for a reroll hunting a flat +mult joker.

Bridge issues: none. All commands (start, blind, disc, play FULLHOUSE/TWOPAIR/PAIR, buy, pack, pick,
endshop, cash) executed cleanly with no ACTION FAILED/retry needed. `est` matched actual score exactly on
every hand played this run (0% deviation), so no >20% est-vs-actual discrepancies to report.

Playbook suggestions:
1. Section 5 (ante 1-2): explicitly warn that Photograph/x-on-face-card jokers only pay off if a face
   card ends up IN the scoring group; for a trips/full-house-heavy opening hand (no faces), a flat
   +mult/+chips joker (Jolly/Mad/Joker/Sly) is strictly safer for ante-1 income since it fires regardless
   of which ranks you draw.
2. Add a rule: if the ante-1 shop (buy + first pack) yields zero flat +mult/+chips jokers and zero
   guaranteed-fire xMult, note that ante-1 Big Blind risk is elevated and prefer to reroll (if $10+ after
   the reroll per existing rule) rather than take a pure-economy pack pick.
3. Consider logging: this run lost solely because the LAST hand of the Big Blind had no straight/flush
   potential and only a weak pair -- confirms playbook 8's "never include a card you still need as filler"
   is not the failure mode here; the failure mode is variance in the final draw with no discards left,
   which the playbook cannot fully mitigate but could flag as an accepted risk of the "hold last discard
   for final hand" rule when the hand right before the final one already used the last discard.
