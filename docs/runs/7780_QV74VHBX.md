  correctly and still came up short by ~20%. The real problem was earlier in ante 5: money went to The Hermit/Justice/

  Two Pair stayed at L2 the entire back half of the run (no Uranus ever reappeared in any shop after ante 4, and I chose

Playbook suggestions:
  1. Section 5's "Level the hand you actually play" advice should be weighted higher relative to card-enhancement
     tarots (Justice/Hierophant/Chariot) once main hand is below L3 by ante 5: a level compounds across every future
     hand of that type, while a single-card enhancement only helps when that exact card is drawn. Consider adding
     "prefer forcing a Celestial pack reroll over Arcana enhancement packs while main hand is below L3 at ante 5+."
  2. shopadvise's default sell-target for freeing a consumable slot should deprioritize the last held card-targeting
     rescue tarot (Death/Strength/Justice/held Hierophant) even when it lists it as "least useful" -- this happened
     THREE times in one run (ante 4 twice effectively, ante 5 once) and each time the override was correct per the
     playbook's own ante-3+ rescue-tarot rule. Worth hard-coding that exception into the advisor rather than relying on
     agent override every time.
  3. Hanging Chad's `est` undercounted actual score by 12-43% in three separate instances this run (ante 2 Small: est
     2560 vs actual 2880; ante 3 Big: est 4240 vs actual 6064; ante 4 boss: est 5712 vs actual 7056) but matched exactly

     which card ends up first in scoring order in a way `est` doesn't always predict -- worth flagging Hanging Chad
     specifically as "est is a lower bound, actual tends to run higher" in section 3.
