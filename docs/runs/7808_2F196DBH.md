## Post-mortem

Binding constraint: no xMult and no hand-type level engine; Straight/Flush-main with flat additive jokers (Abstract, Gluttonous, Photograph) topped out ~1.3k per normal hand and ~2.9k on a made club Flush. Ante 3 boss The Arm (6400) needed ~2.1k per hand over 3 hands; I had $3 and nothing affordable in the shop (every reachable dollar had gone to Photograph, which only doubles base mult).

Decisions I would change:
1. Ante 3 shop: Photograph $5 (+~30%) left me at $2. A reroll hunt or keeping $7 would not have found an xMult either; the real mistake was earlier: ante 1-2 spent every dollar on bridges (Devious perish, Brainstorm rental $7 total, Saturn for a Straight main) while the build never got a permanent xMult or a Pair-family level engine.
2. Ante 2: Saturn (Straight L2) and Straight-draw discards worked at ante 1-2 (4 straights cleared 5 blinds) but locked the run into a Flush/Straight build that the Arm punishes (each played type loses a level).
3. The Arm boss: with 3 hands needing 2.1k each, my only big hand was a 5-club Flush; if there are no clubs after the first discard, the boss is lost. Should have skipped Small AND used the saved rent/shop for... (nothing affordable) - the run was already <0.25 SCORE CHECK at ante 3.

Reusable rules (if-then):
- IF Gluttonous (+3/club) is owned THEN a 5-club Flush scores ~2900-3800 (clubs +3 each BEFORE Photograph x2 resolves if clubs sit left of the first face card): move clubs left of the face card. Card-phase jokers resolve left-to-right inside the scoring order.
- IF Abstract Joker is owned THEN every cheap joker (even perished/dead) adds +3 mult: Two Pair went 100 -> ~900 at ante 2 with 3 jokers. Fill slots with junk jokers before ante 4, do not sell perished ones.
- IF a shop sells a $1 rental copy-joker (Brainstorm) with one perishable scorer THEN it doubles the scorer for the 2 rounds left, worth ~$7 at ante 2 (Straight 1260 -> 2100 cleared Big 1500 in one hand).
- IF the shop after a skipped blind offers a free Uncommon joker that is RENTAL and you already pay rent THEN the hard rule stops it; the Uncommon tag mostly produces a stickered joker at Gold, so value it low.
- IF ratio < 0.25 at ante 3 with $3 and 4 jokers THEN the boss (6400 Arm) is ~5% to clear; the deciding choice was at ante 1-2 (Pair-family build and economy).
