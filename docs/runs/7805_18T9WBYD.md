## Post-mortem

Binding constraint: MONEY -> SCALING. Every shop from ante 1 to 6 ended at $0-5 (peak $18 for one shop, via Hermit), so
the only multipliers were a conditional Seeing Double (ante 3) and a perishable Throwback found at the end of ante 5.
Pair L7 from Double+Orbital at ante 2 carried antes 2-4 almost alone; Splash (ante 5) turned Seeing Double into an
every-hand x2 (club filler) and was the reason ante 5 was cleared. From ante 5 the best possible hand (~36-42k at x2.25)
was below the ante-6 boss pace (40k/hand), so the run had no out at The House.

Decisions I would change:
1. Ante 3 Big shop: reroll $5 + Celestial $4 (no Mercury -> Earth) spent $9 for ~nothing; keeping $11 would have paid $2
   interest twice and funded Throwback/Splash a shop earlier. A Celestial gamble with $11 and 0 r/g xMult is wrong.
2. Ante 3 Small: passed the Economy tag (would have doubled $8 -> $16 at the skip) to take a shop that sold Seeing Double.
   That was right in hindsight, but the money shortage never recovered; with Pair L7 the Small was a one-shot either way.
3. Ante 4: Scary Face{RENTAL} cost $1 + 4 x $3 rent = $13 for +30 chips per face; it was sold at ante 5 to afford
   Throwback. A flat chips rental at ante 4 with $8 was a poor trade versus interest.
4. Ante 6: skipping both blinds was the only line with a real chance (Small 60k pays $0 and its shop would have had $5),
   but with the boss at ~0.7x it was a long shot. The run was decided in the ante-3/4 shops.

Reusable rules (if-then):
- IF the ante-2 (or ante-1) Small has a Double Tag and the Big has an Orbital Tag, THEN skip both: Double copies the
  Orbital's hand (game code sets G.orbital_hand), so it is +6 levels (Pair L1 -> L7 here), enough for antes 2-4.
- IF you own Seeing Double and can buy Splash, THEN buy it and add a club filler to every play: fillers score under Splash,
  so SD fires on every hand (x2) and even fillers add Even Steven mult (ratio 0.19 -> 0.46, est 7.6k -> 16k/hand).
- IF face-down cards (The House/Wheel/Mark) sit in a rank-sorted hand, THEN read their rank from their neighbours: a
  face-down sorted ABOVE a visible Ace is an Ace (made Pair AA at The House); one between JC and 9H is 9-J. Keep that
  knowledge after later draws (the bound only widens because the neighbours change, the card does not).
- IF The House, THEN discard the LOWEST face-downs first (positions 4-8 in a sorted hand): the top ones are your
  high cards and are bounded by the first visible card drawn.
- IF Throwback shows up late, THEN count the skips already made: 3 earlier skips made it x1.75 on purchase.
- IF Temperance is in the shop with 5-6 jokers owned, THEN buy-and-use it ($3 -> +$10 here); IF The Hermit with $9-12,
  THEN use it before rerolling.
- IF slots are full, THEN a Top-up Tag gives nothing: do not count it as a reason to skip.

Advisor/CLI defects:
- shopadvise said `SELL FIRST: b sell 3` (perished Smiley) every shop while Abstract Joker was owned; Abstract counts the
  perished joker (+3 mult), so it should only sell it to free a slot for a buy.
- At The Wheel, `advise` bounded the kept face-down as 3..J after a discard and advised discarding it, although the
  previous sorted hand had already bounded it to 9..J (straight/pair outs). It forgets earlier bounds.
- At The House, `advise` bounded face-down 1 as `A..A` (a known Ace that made Pair AA with AD) but still advised
  `play 2 1 3 4` (AD + three face-downs, no type, est ~19.7k); the correct play was Pair AA + 3C 6S 2H (36378, exact).
  A face-down with a single-rank bound should be treated as that rank.
- `sel` with a face-down card included prints `None scoring None LNone NonexNone` and a deck-average est (20210) even when
  the card's rank is pinned by the sort.
- Ante 4 shop recommended a Jumbo Arcana ($6 of $8) under TIGHT; one Glass/Steel card barely moves a pair round.
- Ante 3 SIM: baseline P(clear next 3 blinds) 0.14-0.17 with Pair L7 even though the Small/Big were one-shot clears;
  the SIM seems to undervalue Pair L7 (or overweight the Club boss).
