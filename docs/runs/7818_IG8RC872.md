**Concrete reusable rules (if-then):**
- IF the advisor ranks a visible scorer or xMult well above an unseen pack, THEN buy the visible scorer. Packs can be all barred rentals.
- IF a rental joker is already held and the shop has a second rental, THEN do not buy it at Gold (the hard rule), even if the sim favours it.
- IF a Gold Small is 3200 or more and you have 0 xMult, THEN the run is already in the death zone; spend every dollar on the cheapest xMult before leaving ante 2.
- IF the boss is The Arm (halves the played hand level), THEN play the strongest made hand early in the boss while its level is still high, then discard toward a straight.
- IF the advisor says "straight draw p 0.46" and the made pair cannot reach the remaining need, THEN breaking the pair is correct.
- IF a Misprint-style random-mult joker is the only scorer, THEN its estimate is unreliable (est 1026 scored 152; est 1193 scored 770). Do not plan a boss clear on it.
