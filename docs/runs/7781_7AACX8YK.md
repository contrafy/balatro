# Run 7AACX8YK (port 7781) - LOSS at ante 1, Small Blind (stake 2, Red Stake)

Ante 1: Zero jokers (never reached a shop). Small Blind (need 300), tag was Boss Tag (not skip-worthy per playbook),
so followed `s` ADVICE and played it (`b blind`).
- Hand 1: TWOPAIR (J,T) idx 1 2 3 4 + filler 8 -> est 120, scored 120. Running total 120/300.
- Hand 2: TWOPAIR (9,5) idx 2 3 5 6 + filler 7 -> est 96, scored 96. Running total 216/300.
- Hand 3 (final, 0 discards left): PAIR (5,5) idx 6 7 + fillers 8 5 4 -> est 40, scored 40 (est matched actual
  exactly). Total 256/300 — short by 44. GAME_OVER.

No shop was ever reached; no jokers, no buys, no skips. Money stayed at $4 throughout (never spent).

Post-mortem: binding constraint was pure bad luck on card draws (no way to reach 300 from 3 pair-only hands with
zero jokers and only 2 discards worth of redraw against 8-card hands each round) combined with zero scoring
jokers being unavoidable this early (game starts jokerless; first shop only comes after Small Blind). Nothing in
the sequence was a misplay — `advise` was followed exactly every turn, and every discard/play matched its ADVICE
line. The decision I would change: none available within this blind — the deck simply didn't deal enough pair
value across 3 hands (best available was three separate Two-Pair-tier draws capping at 120/96/40 = 256, 44 short
of 300). This is a known stake-2 failure mode already documented in the playbook (section 5: "most losses are
ante 1-2 with zero scoring jokers, the $0 Small Blind leaves $4-7 for the first shops") — except this run didn't
even survive to see a shop, since the Small Blind itself was lost before any joker could be bought.

Bridge issues: none. Every command behaved as documented; `est` matched actual score on the final hand exactly
(40 est = 40 actual, 0% error). No `ACTION FAILED` retries needed anywhere in this run.

Playbook suggestions:
1. Consider adding explicit guidance for the Small-Blind-not-skippable-for-EV case: at stake 2 the Small Blind
   pays $0 anyway, so when its tag is NOT skip-worthy (e.g. Boss Tag, which only affects the boss blind), there is
   no income upside to playing it over skipping — the only reason to play is to draw closer to a shop's card
   pool/discard practice. Since a lost Small Blind here ended the run before any joker purchase was possible,
   it may be worth quantifying: is skipping the Small Blind whenever its tag doesn't grant a joker/pack ALWAYS
   correct at stake 2+ (since it pays $0 either way and only risks ending the run for zero reward)? The current
   rule only recommends skipping for specific valuable tags; it doesn't address the asymmetric downside of
   playing a $0-reward blind that can still lose the run.
2. This run is additional data supporting the existing stake-2 note in section 5 about ante-1-2 zero-joker
   losses; no new mechanic was discovered, but it's a clean example of losing the Small Blind itself (not just
   Big/Boss) purely from card variance with 3 pair-shaped hands and 2 discards.
