Post-mortem: Binding constraint was a tooling bug, not money/scaling/luck in the ordinary sense. The `advise` command correctly identified that The Mouth restricts the round to one hand type (it printed the restriction explicitly) but then recommended playing an off-type hand anyway on the very next decision, which scored 0 and burned our second-to-last hand with 0 discards remaining. Once that hand was wasted, the final deal (three pairs, no trips) had zero probability of forming a Full House, so the loss was locked in one decision earlier than it looked. The decision I would change: when `advise`'s own printed note contradicts its own ADVICE line (boss-rule text says "only X may be played" but the command recommends type Y), treat that as the "concrete reason to override" the playbook already allows for, and manually pick from the hands list the option matching the stated boss-locked type (here there was none available — meaning the correct move at that decision point was to recognize we already had zero playable Full House candidates and note the round was likely already lost, then still discard/play conservatively knowing it wouldn't matter). Realistically the round may have been at very poor odds regardless once trips didn't appear, since 0 discards were left before this decision (spent on chasing the first Full House) — the actual root cause one step earlier was spending the last discard (round 6, first hand) to build the first Full House instead of holding a discard in reserve for exactly this scenario (playbook 7a: "Always keep ONE discard for the final hand of a round when your engine depends on finding a specific card"). That 7a rule was not followed here.

Playbook suggestions:
1. Add to section 6 (Bosses) / 4 (Hand decisions): "The Mouth (and any 'one type only' boss): once the round's hand type is locked, `advise`/`hands` may still list and recommend off-type hands with normal-looking `est` values that will actually score 0. If the boss-restriction note is present and none of the listed candidates match the locked type, treat ALL listed candidates as scoring 0 this hand — discard if possible, otherwise play the hand that best sets up a same-type make on the next hand, not the highest `est`."
2. Add to section 7a: reinforce "keep one discard in reserve for the final hand of a round" specifically applies to one-type-restricted boss rounds (The Mouth) even more strongly than suit/rank bosses, since a bad discard-timing decision can make the locked type physically unmakeable with zero recourse.
3. Consider a CLI-level fix: `advise`/`hands` should filter or flag candidate hands that do not match an active "only TYPE may be played" boss restriction, rather than only printing an informational note alongside an unfiltered recommendation.
