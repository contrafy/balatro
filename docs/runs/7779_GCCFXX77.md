Post-mortem: binding constraint = MISPLAY under a boss constraint, not money or scaling. The Mouth locks the round
to the FIRST hand type played; round 2's discards were spent building a Two Pair/Full House (both illegal under
Mouth) before recognizing only Flush scores, wasting both remaining discards on off-type draws. By the time The
Star tarot rescued a Flush, only 2 low-value hands remained to cover the full 10000 need, and the deck no longer
had enough spades/diamonds concentrated for a big flush. The decision I would change: the moment The Mouth is the
boss, `advise`/discard choices must filter candidates to ONLY the type already played (or, before playing hand 1,
choose the type most likely to sustain 3 flush-capable hands in a row) - never discard toward a second type once
locked in. Money was not binding (ended with $4, well above the run-ending threshold); jokers had 0 xMult the
whole run (Supernova/Lusty/Arrowhead/Smiley/Satellite are all flat +mult/+chips/econ), which limited raw scoring
ceiling but was not what caused this particular loss.

Playbook suggestions:
1. Add an explicit rule under section 6/The Mouth: "once the round's FIRST hand fixes the type, every subsequent
   discard decision must target ONLY that type; never spend a discard drawing toward a different type even if it
   looks stronger - it will score 0." The current playbook text for The Mouth ("one type only") states the rule
   but doesn't warn that mid-round discards can silently violate it while chasing a better-looking off-type draw.
2. Before selecting the blind at a Mouth-boss ante, if the held main hand is level-strong on TWO types (e.g. both
   Two Pair and Flush look viable), prefer opening with the type that has more supporting jokers (Arrowhead here
   clearly favored Flush(spades) over Two Pair) since that commits the whole round.
3. Investigate the Arrowhead+Flush est-undershoot (5440 est vs 7828 actual, ante 3 Eye boss) with a couple more
   logged samples before trusting `est` at face value for suit-flat-chip jokers on 5-card same-suit hands.
