## Post-mortem

**Best result:** Stake 1 (White), Ante 6, lost to The Needle boss blind (need 20000, scored 15147, short by 4853).

**Binding constraint:** Scaling ceiling, not misplay. The Pair engine reached L12 (175 base chips x13 mult) plus +18 mult (Abstract Joker) and +50 chips (Sly Joker) and +20 mult (Half Joker <=3 cards) - a very strong flat-scaling build - but had only ONE xMult source (Seeing Double, a conditional x2 that fires reliably but doesn't compound with itself) for the entire run. The Needle boss forces exactly one scoring hand with no chance to bank partial progress across multiple hands (unlike every other blind this run, where "pacing" - playing weak hands to accumulate progress across 3-4 hands - was the winning strategy per advise). A single flat-scaled Pair hand simply could not clear a 20000 target when the build had no second xMult multiplier to compound the mult further. By ante 6, playbook 7b's reference builds note "Two or more xMult sources... is the minimum" for ante 6-8 - this run never got there despite consistently following the reroll-for-xMult rule.

**One decision I would change:** At ante 5, when Burnt Joker appeared (95-ranked, sold Gift Card for it), I should have kept rerolling one more round afterward specifically for a 2nd xMult before committing further shop budget to hand levels/enhancements - the Pair level was already at L7-L8 by ante 5, comfortably ahead of the "L4+ by ante 6-8" minimum, while xMult stayed stuck at 1. With hindsight, ante 5-6 gold should have gone almost entirely into xMult-hunting rerolls rather than the 2nd/3rd Celestial-pack Mercury picks (Pair L9->L11 gave diminishing returns compared to what a genuine 2nd xMult would have added multiplicatively). The Telescope voucher (guaranteed Mercury) was a good buy but should have been spent on money-preserving choices to keep rerolling instead.

**CLI/bridge issues:**
- `shopadvise` persistently reported "you own 0 xMult joker(s)" throughout antes 4, 5, and 6 even after Seeing Double (ab={"extra":2}, clearly an xMult-shaped ability) was purchased and visible in the jokers list on every subsequent call. This looks like a real bug in the advisor's xMult-counting logic (possibly not recognizing the ab format used by Seeing Double specifically), not a game-state issue — the joker itself worked correctly in actual scoring (Pair T with two different-suited cards including a Club scored roughly 2x a plain pair estimate: 15640 vs ~7800 baseline).
- `shopadvise` twice suggested selling a valuable held tarot (The Hierophant, saved for pair-rank chip enhancement / boss rescue) to buy comparatively low-value items (The Fool, a generic Pluto/Venus planet for an unplayed hand type). Declined both times by instead selling the second, lower-value held consumable (Judgement, which needed a joker-slot sacrifice to ever redeem and had uncertain payoff) to free the slot. This pattern suggests the advisor's consumable-slot-freeing heuristic picks the first held tarot alphabetically/by-index rather than by value - worth flagging.
- No other action errors, retries, or `ACTION FAILED` messages encountered this entire run; all CLI actions (play/disc/sel/pick/use/buy/sell/vouch/pack/reroll/endshop/blind/cash) worked as documented on the first try.

**Playbook suggestions:**
1. Add explicit guidance for The Needle boss: since it forces exactly one scoring hand (no partial-progress banking across hands like every other blind), treat its target number as needing FULL clearance from a single play, and weight xMult-hunting shop spend more heavily in the ante immediately before a known/likely Needle ante, since flat-chip/mult levels alone may not be enough once a single-hand requirement removes the "pacing across hands" strategy that carried most of this run.
2. Consider tightening the ante-4+ xMult reroll rule: this run followed "reroll until $15 floor" faithfully across roughly 8 shop visits from ante 4-6 and never found a 2nd xMult (consistent with the 1-in-45 rarity noted in 7a), suggesting either the money floor should be raised further to sustain longer hunts, or an explicit fallback should be documented for when zero/one xMult persists into ante 6+ (e.g., prioritize retrigger effects like Hanging Chad/Deja Vu-Red-Seal harder, since those found in this run were the closest thing to a true multiplier substitute).
3. Flag the shopadvise "0 xMult" display bug and the tarot-selling-priority heuristic (both described above) for the tool maintainers, since an agent following ADVICE literally without cross-checking the jokers list would have sold a genuinely useful held tarot for a much weaker one.
