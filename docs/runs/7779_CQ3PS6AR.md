Post-mortem:
Binding constraint: scaling. We never found an xMult joker in 2+ antes of hunting (rerolled repeatedly at ante 3
  and 4 with $ spent and nothing but flat PLUS/UTIL/ECON jokers appearing), and our base hand (Pair, later
  Two Pair/Trips as backups) only reached L4/L2/L3 -- chips*mult growth could not keep pace with the ante 4 Big
  Blind's 7500 requirement once a bad, pair-poor deck stretch happened right when discards ran out. Money was
  also thin ($7-12 most of ante 3-4) from reroll-hunting for xMult that never paid off, so we had no chips-boosting
  purchase (Scholar, Walkie Talkie, Droll) in reserve either, having judged them off-build.
One decision I would change: at ante 3-4, once 2 reroll attempts per shop found nothing but PLUS/ECON/UTIL jokers,
  I should have banked the money into hand levels (more Celestial packs) or a flat +chips/+mult joker that DOES
  support Pair/Trips (e.g. Scholar's +20 chips +4 mult per Ace, which we actually had synergy for via multiple Ace
  pairs) rather than continuing to burn rerolls chasing xMult with diminishing bankroll. A stronger flat-mult base
  would have absorbed the ante-4 cold-deck stretch that ended the run.
Bridge issues: none. Every `play`/`disc`/`pick`/`buy`/`cash` command worked on the first try this run; no
  ACTION FAILED retries were needed.
IMPORTANT VERIFIED FINDING (repeated 4x this run): the `advise`/`hands` est calculator computes Shoot the Moon's
  "+13 mult per Queen held" bonus assuming the Queen stays HELD IN HAND (unplayed), but the advisor's own suggested
  filler list sometimes INCLUDES the Queen as a filler card, which actually plays it and voids the bonus (real
  Balatro "held in hand" semantics: only cards NOT in the played selection count). Verified twice that following
  the advisor's filler list verbatim would have scored ~1200-1250 (base, no bonus) against needs of 600-1600,
  passable there only by margin, but overriding to keep the Queen out of the filler list produced 4-9x higher
  actual scores that matched est exactly. Also verified twice more where the advisor's OWN filler choice already
  excluded the Queen (no override needed) -- so the bug is inconsistent, not universal.
Playbook suggestions:
  1. Add an explicit rule: when Shoot the Moon (or any other "+X per <rank> held" joker) is active and the shown
     est assumes the bonus, cross-check the ADVICE's filler list for that rank's card; if present, replace it with
     a same-count set of fillers that exclude it (dropping a filler slot below need if no substitute exists is
     fine -- just don't include the target card).
  2. Add to Do-Not list: don't spend 2+ consecutive reroll attempts (ante 3-4) hunting xMult with no result while
     ignoring an available flat-mult joker (like Scholar) that clearly synergizes with cards already seen this run
     (e.g. repeated Ace pairs) -- bank the flat scaling instead once 2 rerolls in one shop visit whiff.
  3. Confirm the "never reroll under $10 in antes 1-3" rule already caught 2 bad ADVICE calls this run (ante 3,
     twice) -- this rule is working as intended and should stay.
