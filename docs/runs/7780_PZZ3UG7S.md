# Run PZZ3UG7S (port 7780) - stake 3 (Green Stake) - LOSS at ante 1 Big Blind

Ante 1: Zero jokers, $4 start. `s` showed ADVICE `b skip` on the Small Blind (300, tag=Uncommon Tag,
"gives a free Uncommon joker"). Skipped it. Went straight to Big Blind (450, tag=Foil) with 0 jokers
and 0 shop visits so far (the Uncommon Tag's joker was never delivered before this blind - see
Bridge issues below).
- Hand 1 (Big Blind): dealt QD TC 9S 5H 5C 4H 3D 2D (Pair 5). `advise` said DISCARD twice to build
  around the pair (kept drawing toward Two Pair/Full House), ending with a made Two Pair (5,5/2,2)
  after using both remaining discards - each discard only removed the non-paired cards so the Two
  Pair floor was never at risk. Played TWOPAIR 3 4 5 6 7 (idx of 5,5,4,4 + filler): est 76, actual 76.
  score 76/450.
- Hand 2: dealt QC JD TS TD 9D 7C 6D 2D - 5 diamonds (JD TD 9D 6D 2D). `advise`/`hands` found FLUSH D
  est 288 (need 374). Played FLUSH 2 4 5 7 8: est 288, actual 288. Score 364/450, 1 hand left, 0
  discards, need 86 more.
- Hand 3 (forced final hand, 0 discards): dealt KH KD QC JC TS 8D 7C 3C - only one pair (K), no
  straight (missing 9), no flush (4 clubs, needed a 5th). `advise` gave PAIR FACE K, idx 1 2, est 60
  vs need 86 - no consumable held to rescue it (no shop had been visited yet, ante 1, first blind).
  Played PAIR 1 2 6 5: est 60, actual 60. Final score 424/450 - **lost the Big Blind by 26**, ending
  the run at ante 1 with zero jokers ever acquired.

Post-mortem: binding constraint was the SKIP decision on the Small Blind. The Uncommon Tag's free
joker did not materialize before the Big Blind (it only pays out at the next shop, which comes
*after* the Big Blind since the Small Blind's shop was also forfeited by skipping). So the deck
entered a 450-chip Big Blind with the same zero-joker ~150/hand ceiling the playbook already
documents as a loser at stake 3 ante 1-2 (see 7a "STAKE 3 ANTE 1-2" and "ANTE-1 SKIP RULE REVISED").
The decision I would change: do NOT skip the ante-1 Small Blind on stake 3 even for a joker-granting
tag (Uncommon/Rare/Buffoon/Top-up/Coupon), because the tag's reward lands only at the shop *after*
the next blind, not before it - so skipping still sends a jokerless deck straight into the Big Blind
undefended. Play the Small Blind (it clears easily with a floor Two Pair/Pair for $0 income at
stake 3, still worth it) and take that shop first, THEN take Uncommon Tag rewards at later skips
once a scoring joker is already in hand. This run lost by only 26 chips (424/450) - a single flat
+mult/+chips joker (even a $3 Jolly/Sly) bought from an ante-1 shop before the Big Blind would very
likely have cleared it.

Bridge issues: none - no ACTION FAILED, no connection errors, no stale-index aborts. All `play`/`disc`
commands matched the CLI's TYPE check on the first try; all `est` values matched actual scores exactly
(76/76, 288/288, 60/60), so no >20% est-vs-actual discrepancies to report.

Playbook suggestions:
1. Section 5 / `s` ADVICE text is misleading for the ante-1 tag-skip rule: it says skipping the Small
   Blind "gives a free Uncommon joker" as if the reward is available immediately, but the joker is
   only granted at the *next shop*, which is after the Big Blind, not before it. On stake 3 (and
   likely stake 2), a jokerless deck skipping the Small Blind for a joker-tag still faces the 450 Big
   Blind with zero jokers. Either (a) clarify the ADVICE text to say "the joker arrives after this
   Big Blind, not before it" so the agent knows not to expect help clearing it, or (b) reconsider the
   underlying rule: at ante 1 with zero jokers, do not skip the Small Blind even for a joker tag,
   since skipping trades a free $0 clear + an ante-1 shop visit for nothing that helps the very next
   (harder) blind.
2. Add this run's numbers (424/450, lost by 26, zero jokers, Uncommon Tag skip) to the "STAKE 3
   ANTE 1-2" data point list in section 7a as further evidence for suggestion 1.
3. Confirm/verify in the harness or CLI whether skip-tag rewards (joker/pack) are actually delivered
   at the shop immediately following the skipped blind, or only after the *next* blind is cleared -
   this run's evidence suggests the latter, but this should be double-checked against the bridge's
   tag-handling code so the ADVICE line's timing claim can be corrected precisely.
