## Post-mortem

Binding constraint: scaling. The whole build was Raised Fist (+2x lowest held, max +22 mult) + chips jokers (Sly, foil Runner, Scary Face). One hand topped at ~4500-5100 at ante 4, and 13500 needs 4500 x 3 with no variance. No xMult was ever seen in 7 shops/packs; $15 sat unspent in the final shop-less Big.

Decisions I would change:
1. Ante 4 shop 1 ($7): bought Delayed Gratification (+$4/round if no discards) instead of the Celestial pack ($4, Mercury/Pair level) ; then skipped the Small for Handy ($12). A Pair level (+15 chips x ~22 mult = +330/hand) or any chips joker would have covered the 608 gap. DG gave nothing before the death.
2. Ante 3 shops: I left with $18-24 twice (after skipping a junk Buffoon pack) instead of buying Celestial/Arcana for levels; the run died with $15 unspent. Money does not score.
3. Ante 4 Big hand 2: I discarded 7S 5D and drew 9S 4C (no gain); hand 3 had no way to reach 5118. A different order (play Two Pair first, keep discards for trips/FH) would not obviously have helped; the real gap was chips.
4. Gros Michel (+15 mult, 1/6 destroyed per round) died the first round I held it; it was worth +125% only for that one hand. On a Fist build the mult is already ~22, so chips (not +mult) were the lever and Gros Michel was the wrong buy.

Reusable rules (if-then):
- IF you own Raised Fist, THEN play 5 cards (pair/trips + low fillers) and HOLD 3 high cards: Fist adds 2 x nominal of the lowest HELD card by rank (J/Q/K count 10, A 11, face-down cards count 10): hold Q J T or A A K for +20-22 mult. A 1-card High Card with 7 cards held is worth ~600 vs ~4000 for the same hand with 3 high cards held. Max Fist mult is +22, so after ante 3 stack CHIPS (Sly, Banner, Runner, Scary Face, planets) and an xMult; +mult jokers add little.
- IF face-down cards (The Mark) are held with Raised Fist, THEN they count as 10: est shows ~300 but the real play scores ~3000 (est 294 vs actual 3234/2926).
- IF a Fist/held-card build clears ante 3 with ~5000 per hand, THEN ante 4 (13500 Big, 3 hands) needs 4500 x 3 with no variance: before ante 4 buy two chips jokers or levels with ALL spare money; do not end a shop holding $15+.
- IF Investment tag is offered on a Small at ante 1-2 while broke, THEN skip it: pays $25 after the next boss (7812: $1 -> $32) and saves a rent charge.
- IF Handy tag is on the Small, THEN skipping pays $1 per hand played this run (12 hands = +$12).
- IF Delayed Gratification is considered, THEN it pays only if you never discard; it does not score and costs a slot: not a fix for under-scaling.
