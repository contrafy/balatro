## Post-mortem
Binding constraint: misplay/luck combo, not money or joker scaling - jokers and levels (Two Pair L4 + Clever Joker +
Green Joker growing mult) were strong enough to nearly 3x score every hand; the loss came from discard-budget management
in the final boss round. All 3 discards were spent early in the round chasing an unnecessary quad-2s upgrade instead of
being held in reserve for the last hand, so when the last hand drew no second pair (only one Jack pair, rest singletons)
there was no way to fix it and the only legal play (Straight, unleveled, no Clever Joker synergy) scored far below the
two-pair average that was carrying the run.

Decision I would change: in the boss round, after locking in 2 discards for the first hand's quad-2 chase, I should have
banked the 3rd discard rather than immediately spending it too ("disc 1 4" on the 4th redraw) - or, more simply, once the
scoring hand (two pair) was already very strong (880+ est) I should have stopped optimizing further and preserved discards
for hand 2 and hand 3 insurance, since a Two-Pair-focused build has no fallback hand type once pairs run out. A generic
rule: never burn every discard chasing marginal upside on hand 1 of a 3-hand round when the strategy depends on a
resource (pairs) that can run dry - always reserve at least 1 discard for the final hand of a round when your build has
only one strong hand type.

Bridge issues (exact text):
- After selecting a Planet consumable from a Celestial/Buffoon pack pick, the CLI sometimes prints a stale
  "Pack (choose N): ..." listing with remaining cards still legal (SELECT_PACK_CARD) even though the pack only grants one
  pick and the game has already moved to [SHOP]. Calling `pick N` again in that state returns
  `ACTION FAILED: Invalid pack card index None` with the state line showing [SHOP] already. Workaround: run `s` after a
  pack pick to get the authoritative phase before deciding whether another pick is available. No data was lost either
  time this happened; it just cost one wasted CLI call.
- The `hands` command's `est` figures do NOT account for The Head boss's suit-debuff: it displayed a Flush and Pair using
  fully-debuffed cards' full face-value card chips as if they scored normally. Had to manually inspect the hand printout
  for `(DEBUFF)` tags and hand-pick alternate card indices (e.g. `play TWOPAIR 2 4 5 7` instead of the suggested
  `2 3 5 6`) to route around debuffed cards. Actual score after doing this (624) exceeded the flawed est for the
  debuff-including combo (468), confirming the manual override was correct.
- `est` numbers in general under-predicted actual score late in a round by 20-40% in this run (Green Joker's mult grows
  per hand played within the round, plus possibly other effects), so `est` should be treated as a floor, not the ceiling,
  when deciding whether a weaker/cheaper hand can still clear a `need` gap.
- `sell N` mid-round (during SELECTING_HAND) worked exactly as documented for Luchador and is confirmed to disable the
  current boss blind's effect (Levels: stayed un-debuffed by The Arm for the rest of that boss round after the sale).

Playbook suggestions:
1. Add to section 4 (hand decisions): "If your build's main scoring hand depends on a finite resource (e.g. pairs),
   reserve at least 1 discard for the final hand of every round once you've already secured a strong (est-clearing)
   hand from an earlier one - do not spend all discards chasing upside on hand 1."
2. Add a note that `hands`' `est` should be read as a lower bound in the back half of a round when a per-hand-played
   scaling joker (Green Joker, etc.) is active, since actual scores ran 20-40% above est in every multi-hand round
   observed this run.
3. Confirm and promote the Luchador boss-answer combo more strongly: selling Luchador via `sell N` mid-round (after
   `blind` is selected but before playing) fully disables a dangerous permanent-debuff boss like The Arm for that whole
   boss round - this is cheap ($2 sell-back on a $5 buy) insurance and should be bought proactively in the ante's prior
   shop specifically for antes with The Arm/similarly punishing bosses shown on the upcoming-boss line.
4. Flag the `hands` est-vs-debuff bug (The Head / suit-debuff bosses) explicitly in section 6 so agents know to
   cross-check `(DEBUFF)` tags on cards and hand-pick indices rather than trusting the suggested index list verbatim.
